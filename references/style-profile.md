# 建立你自己的风格

第一次用、或者用户想换风格时做。目的：让每个人的视频长得像他自己，而不是像这个 skill 的作者。

结果是两个文件：`theme.css`（画面变量）和 `style.md`（文字规则），放在用户的工作区，例如 `我的风格/`，路径写回 SKILL.md 的“创作者设定”表。

## 路线 A：有参考视频（推荐）

请用户给 3–5 条视频：自己以前发过、觉得满意的，或者喜欢、想靠近的别人的。

1. 按 `reference-analysis.md` 逐条拆：总览帧、钩子帧、OCR 字幕、帧差。
2. 每条记下这些项，再找共同点：
   - **底色和主色**：在总览帧上取色（背景、大字、标签、重点词），记 HEX。
   - **字体气质**：黑体粗重、圆体、衬线、手写；大字占屏宽多少。
   - **边框和阴影**：无边、细线、粗黑边硬阴影、柔阴影、玻璃。
   - **动效能量**：每分钟新元素数、帧差中位数（停不停）、转场方式（硬切、闪白、模糊叠化、遮罩）。
   - **人和素材的比例**：全屏人多，还是素材多、小头像多。
   - **字幕**：位置、字号、描边还是底条、重点词怎么标、有没有英文。
   - **封面**：标题位置和字数、人物大小、道具、颜色数量。
3. 把共同点写成 `style.md`，取色写进 `theme.css`。
4. **不抄别人的。** 参考别人的视频时只学手法和气质，颜色至少换主色，构图和署名方式不照搬。拿去用的是“像谁”，不是“变成谁”。
5. 用 `styles/neutral.css` 打底改，出 3 张样帧（开头、中段卡片、章节页）给用户看，按反馈调到满意。

## 路线 B：没有参考视频

问用户几个问题，一次问完：

1. 你的视频想给人什么感觉？（例如：专业冷静 / 热闹好玩 / 温和亲切 / 极简高级）
2. 有没有一定要用的颜色？比如品牌色、头像或衣服常穿的颜色。
3. 有没有讨厌的样子？（例如：不要卡通、不要深色、不要花字）
4. 屏幕录制多，还是本人出镜多？
5. 字幕要不要英文？

按回答在下表里选一档，填进 `theme.css` 和 `style.md`，再出 3 张样帧确认：

| 感觉 | 边框和阴影 | 动效 | 转场 |
|---|---|---|---|
| 专业冷静 | 细线或无边，柔阴影 | `soft` | 模糊叠化 |
| 热闹好玩 | 粗边硬阴影 | `v4` | 闪白、斜切 |
| 温和亲切 | 无边大圆角，柔阴影 | `soft` | 叠化 |
| 极简高级 | 无边无阴影，大留白 | `soft`，元素少 | 硬切 |

颜色：一个底色、一个主色、一个强调色就够。不要直接用 `styles/` 里的示例。

## style.md 的格式

```markdown
# 我的风格

- 一句话：（例如“冷静的工程师笔记感”）
- 动效能量：soft / v4
- 版式偏好：人像为主 / 录屏为主（page-screen.html）/ 混合
- 字幕：位置、字号、重点词标法、是否双语
- 章节页：要不要，长什么样
- 大字：每屏几个字，放人前还是人后
- 结尾署名：
- 封面构图：标题位置、人物位置和大小、道具、最多几种颜色
- 不要：（用户明确讨厌的）
- 参考来源：（拆过哪几条视频，只记手法）
```

## 以后怎么用

- 每条视频复制 `theme.css` 到 `page.html` 旁边。
- 写场景、做封面前先读 `style.md`。
- 用户对某条成片的风格提出意见，改的是风格文件，不是只改这一条。
